## Задание 1. Расстояния между городами

### Задание
00_distance

Дан словарь координат городов:

```python
sites = {
    'Moscow': (550, 370),
    'London': (510, 510),
    'Paris': (480, 480),
}
```

Составить словарь словарей расстояний между ними. Расстояние на координатной сетке вычисляется по формуле:

```
((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5
```

### Описание проделанной работы

1. Координаты городов из словаря `sites` вынесены в отдельные переменные `moscow`, `london`, `paris` — для удобства чтения формул.
2. Создан пустой словарь `distances`.
3. Для каждой пары городов вычислено расстояние по заданной формуле и записано во вложенный словарь: `distances[город1][город2]`.
4. Результат выведен на экран через `print()`.

### Код программы

```
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

sites = {
    'Moscow': (550, 370),
    'London': (510, 510),
    'Paris': (480, 480),
}

distances = {}

moscow = sites['Moscow']
london = sites['London']
paris = sites['Paris']

distances['Moscow'] = {}
distances['Moscow']['London'] = ((moscow[0] - london[0]) ** 2 + (moscow[1] - london[1]) ** 2) ** 0.5
distances['Moscow']['Paris'] = ((moscow[0] - paris[0]) ** 2 + (moscow[1] - paris[1]) ** 2) ** 0.5

distances['London'] = {}
distances['London']['Moscow'] = ((london[0] - moscow[0]) ** 2 + (london[1] - moscow[1]) ** 2) ** 0.5
distances['London']['Paris'] = ((london[0] - paris[0]) ** 2 + (london[1] - paris[1]) ** 2) ** 0.5

distances['Paris'] = {}
distances['Paris']['Moscow'] = ((paris[0] - moscow[0]) ** 2 + (paris[1] - moscow[1]) ** 2) ** 0.5
distances['Paris']['London'] = ((paris[0] - london[0]) ** 2 + (paris[1] - london[1]) ** 2) ** 0.5

print(distances)
```

## Задание 2. Площадь круга и точки

### Задание
01_circle
Дан радиус круга `radius = 42`. Нужно:

1. Вывести площадь круга с точностью до 4 знаков после запятой, приняв π = 3.1415926.
2. Для точки `(23, 34)` вывести `True`, если она внутри круга с центром `(0,0)` и радиусом 42, иначе `False`.
3. Аналогично для точки `(30, 30)`.

### Описание проделанной работы

1. Площадь круга вычислена по формуле `S = π · r²`, результат округлён через `round(area, 4)`.
2. Для каждой точки вычислено расстояние до начала координат: `√(x² + y²)`.
3. Расстояние сравнено с радиусом: `distance <= radius` — результат сразу булев (`True`/`False`), выведен через `print()`.

### Код программы

```
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

radius = 42

pi = 3.1415926
area = pi * (radius ** 2)
print(round(area, 4))

point_1 = (23, 34)
x1 = point_1[0]
y1 = point_1[1]
distance_1 = (x1 ** 2 + y1 ** 2) ** 0.5
print(distance_1 <= radius)

point_2 = (30, 30)
x2 = point_2[0]
y2 = point_2[1]
distance_2 = (x2 ** 2 + y2 ** 2) ** 0.5
print(distance_2 <= radius)
```

True
False
```

05_zoo

1. Вставить `'bear'` между `'lion'` и `'kangaroo'`.
2. Добавить птиц из списка `birds` в конец.
3. Убрать слона.
4. Вывести номера клеток, где сидят `'lion'` и `'lark'` (в понятной человеку нумерации).

### Описание проделанной работы

1. Использован метод `.insert(1, 'bear')` для вставки по индексу.

## Задание 10. Множества: цветы в саду и на лугу

### Задание
08_garden
Даны два кортежа — цветы в саду (`garden`) и на лугу (`meadow`). Создать множества, вывести:

- все виды цветов;
- те, что растут и там, и там;
- те, что только в саду;
- те, что только на лугу.

### Описание проделанной работы

1. Из кортежей созданы множества `garden_set` и `meadow_set` (дубликаты автоматически убраны).
2. Для вывода использованы операции над множествами:

- объединение `|` — все виды;
- пересечение `&` — общие;
- разность `-` — только в одном из множеств.

### Код программы

```
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

garden = ('ромашка', 'роза', 'одуванчик', 'ромашка', 'гладиолус', 'подсолнух', 'роза')
meadow = ('клевер', 'одуванчик', 'ромашка', 'клевер', 'мак', 'одуванчик', 'ромашка')

garden_set = set(garden)
meadow_set = set(meadow)

print('Все виды цветов:', garden_set | meadow_set)
print('Растут и в саду, и на лугу:', garden_set & meadow_set)
print('Только в саду:', garden_set - meadow_set)
print('Только на лугу:', meadow_set - garden_set)
```

### Результат работы
```

## Задание 11. Стоимость товаров на складе

### Задание
10_store
Даны словарь кодов товаров `goods` и словарь партий товаров `store`. Для каждого товара вывести его общее количество и общую стоимость. **Без циклов** — задание на ручное вычисление.

### Описание проделанной работы

1. Для каждого товара получен его код через `goods['Название']`.
2. По коду найдены партии товара в `store`.
3. Для каждой партии вычислено `количество × цена` и просуммировано.
4. Общее количество — сумма количеств по всем партиям.
5. Результаты выведены в формате `<товар> - <кол-во> шт, стоимость <сумма> руб`.

### Код программы

```
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

goods = {
    'Лампа': '12345',
    'Стол': '23456',
    'Диван': '34567',
    'Стул': '45678',
}

store = {
    '12345': [{'quantity': 27, 'price': 42}],
    '23456': [{'quantity': 22, 'price': 510}, {'quantity': 32, 'price': 520}],
    '34567': [{'quantity': 2, 'price': 1200}, {'quantity': 1, 'price': 1150}],
    '45678': [{'quantity': 50, 'price': 100}, {'quantity': 12, 'price': 95}, {'quantity': 43, 'price': 97}],
}

# Лампа
lamp_code = goods['Лампа']
lamp_item = store[lamp_code][0]
lamp_quantity = lamp_item['quantity']
lamp_price = lamp_item['price']
lamp_cost = lamp_quantity * lamp_price
print('Лампа -', lamp_quantity, 'шт, стоимость', lamp_cost, 'руб')

# Стол
table_code = goods['Стол']
table_1 = store[table_code][0]
table_2 = store[table_code][1]
table_quantity = table_1['quantity'] + table_2['quantity']
table_cost = table_1['quantity'] * table_1['price'] + table_2['quantity'] * table_2['price']
print('Стол -', table_quantity, 'шт, стоимость', table_cost, 'руб')

# Диван
sofa_code = goods['Диван']
sofa_1 = store[sofa_code][0]
sofa_2 = store[sofa_code][1]
sofa_quantity = sofa_1['quantity'] + sofa_2['quantity']
sofa_cost = sofa_1['quantity'] * sofa_1['price'] + sofa_2['quantity'] * sofa_2['price']
print('Диван -', sofa_quantity, 'шт, стоимость', sofa_cost, 'руб')

# Стул
chair_code = goods['Стул']
chair_1 = store[chair_code][0]
chair_2 = store[chair_code][1]
chair_3 = store[chair_code][2]
chair_quantity = chair_1['quantity'] + chair_2['quantity'] + chair_3['quantity']
chair_cost = (chair_1['quantity'] * chair_1['price']
              + chair_2['quantity'] * chair_2['price']
              + chair_3['quantity'] * chair_3['price'])
print('Стул -', chair_quantity, 'шт, стоимость', chair_cost, 'руб')
```

### Результат работы
```
Лампа - 27 шт, стоимость 1134 руб
Стол - 54 шт, стоимость 27860 руб
Диван - 3 шт, стоимость 3550 руб
Стул - 105 шт, стоимость 10311 руб
```
